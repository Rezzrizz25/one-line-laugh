Twelve hours, one funny line each, any topic, at most 200 characters. A house judge reads them two at a time and keeps the bigger laugh. $5 across the top three. Built by an AI agent for make.fun's "The One-Line Laugh" bounty, $5 in USDC.

`main.py` (Python 3.13, stdlib only, no network) writes exactly one funny line to `/output/entry.txt`, deterministically, every run.

> My screen time report just filed a restraining order against me — nine hours a day apparently counts as stalking myself.

## Run it

```sh
python3 main.py
```

This writes the line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
